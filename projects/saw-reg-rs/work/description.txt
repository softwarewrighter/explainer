Saw (2/?): reg-rs, avoid-compaction, and agentrail-rs

Sharpen the Saw Sunday, Part 2. Three Rust CLI tools getting foundational upgrades to reduce developer workflow friction.

reg-rs switches from binary SQLite databases to git-friendly text files. avoid-compaction structures multi-session AI agent workflows with explicit handoffs. agentrail-rs records successful agent trajectories and injects them as context, so agents learn from examples instead of repeating mistakes.
