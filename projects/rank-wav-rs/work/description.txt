Your AI coding agent just generated fifty sound variants. How do you find the best ones without listening to each one manually?

rank-wav is a Rust command-line tool that analyzes WAV files and ranks them by acoustic measurements. It extracts four features from each file: RMS level for volume, zero-crossing rate for texture, spectral centroid for brightness, and spectral bandwidth for complexity.

The tool offers two scoring modes. Pleasing mode favors warm, smooth sounds with good presence. Best mode prioritizes clarity and balanced frequency content. Both scores are computed for every file, letting you sort by either preference.

Output options include formatted tables for quick review and JSON for scripting. Pipe results to jq to extract top candidates programmatically.
