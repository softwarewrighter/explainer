reg-rs: Snapshot Regression Testing for CLI Tools

A Rust CLI tool that captures command output as baselines and detects regressions when that output changes. Shell aliases make the workflow fast and interactive. A built-in web dashboard with SSE shows test results updating in real time.

Shell Aliases:
- adrg: Add a test (captures baseline)
- rnrg: Run tests (detects changes)
- lsrg: List tests with status
- shrg: Show test details and diffs
- uprg: Rebase (accept new output)
- rmrg: Remove a test
