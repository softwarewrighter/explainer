PJMAI-RS: Project Management for AI Agents

A fast, Rust-based CLI tool for managing multiple projects with fuzzy matching, stack-based navigation, and AI agent integration.

INSTALL:
git clone https://github.com/sw-cli-tools/pjmai-rs.git
cd pjmai-rs && ./install.sh --local .

LINKS:
GitHub: https://github.com/sw-cli-tools/pjmai-rs
Documentation: https://github.com/sw-cli-tools/pjmai-rs#readme

FEATURES:
- Shell integration with bash/zsh
- Fuzzy project switching (chpj)
- Stack-based navigation (pspj/popj)
- Environment management (evpj)
- Auto-discovery of git repos (scpj)
- AI agent context generation (ctpj)
