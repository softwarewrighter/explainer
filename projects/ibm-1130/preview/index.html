Narration Script (~14s)

This simulator also visualizes punch cards. The source card shows readable assembly, label, opcode, and operands across eighty columns. The object deck looks different. Dense binary patterns encode machine instructions using the four to three punch format the eleven thirty card reader understood.

Cards shown:

02d - Selectric Console HAS OBS

Narration Script (~15s)

The eleven thirty one console used an IBM Selectric as its printer. Watch this simulation type an assembler listing at fifteen characters per second. Job control cards appear first, then the listing. Each line shows statement number, address, hex object code, and source.

Listing columns:

  • STMT: Statement number
  • ADDR: Hex memory address
  • OBJECT: Hex machine code
  • SOURCE STATEMENT: Assembly code

04 - Web UI Demo HAS OBS

Narration Script (~38s)

Watch as I assemble this program that adds two numbers. The machine code appears below, each instruction with its hex encoding. Now I step through. The accumulator loads five from address thirty. Add brings in seven from address thirty one. The result, twelve, now sits in the accumulator and the positive flag lights up. One more step stores our answer to memory. Now a more advanced example. This program demonstrates memory mapped registers. The eleven thirty stores index registers at addresses one, two, and three. Watch the memory grid highlight as values flow into these special locations. Finally, indexed addressing, the instruction loads from address fifty plus the index register, giving us the value at address one fifty.

Examples shown:

  • Example 1: Add Two Numbers (LD, A, STO, WAIT)
  • Example 2: Memory-Mapped Index Registers (XR1-XR3)
