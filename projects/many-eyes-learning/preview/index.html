02 - Overview TTS READY

Narration Script (24.3s)

The core idea is simple. Instead of one agent exploring alone, we use multiple scouts with different strategies. Random scouts explore everywhere. Epsilon greedy scouts balance exploration and exploitation. Curious scouts seek novel states. Optimistic scouts assume unknown areas have high value. Together, they cover more ground and find rare rewards that a single explorer would miss.

03 - Architecture TTS READY

Narration Script (22.4s)

Here is how the system works. Each scout explores the environment and collects trajectories, states, actions, rewards, and outcomes. These experiences flow into a shared pool. A single learner, a DQN with target network, trains on the aggregated data. The updated policy can then flow back to the scouts, improving their exploration over time.
